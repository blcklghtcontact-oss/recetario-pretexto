# Recetario Café Pretexto

Recetario de barra de Café Pretexto (estilo libreta). Sitio: GitHub Pages.

- `datos.json`: recetas, inventario y técnica (se genera desde el vault de Obsidian de Alberto: `wiki/cafeteria-pretexto/`).
- La IA (Qwen 2.5 con WebLLM) corre en el navegador de cada aparato; la primera vez descarga el modelo.
- Las notas y cambios se guardan en el aparato donde se hacen; el botón "cambios sin subir" permite copiarlos para subirlos aquí.
